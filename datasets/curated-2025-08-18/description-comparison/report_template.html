ScaBench vs Nethermind finding text

Nethermind's scorer repo ships its own copy of 11 ScaBench projects as ground truth. Same findings, same IDs, but with the text cleaned up. This report shows exactly what was removed or reformatted, checks whether any audit content was lost, and measures how much of the same noise remains in the 20 projects Nethermind did not clean.

Where the removed characters come from

Share of each project's ScaBench description text, by what Nethermind did with it. Diffs ignore whitespace and backticks, so formatting-only edits count as kept. Every removed run is labelled by the marker it contains; a removal with no marker would show up as “unexplained”. Discussion covers sponsor, judge and warden comments after judging (some quote code) plus mitigation status. Spill-over is text from other parts of the report glued onto the last finding of a section: the QA report, mitigation-review findings, and the C4 disclaimer.

Titles and severities

Titles are what the judge reads first. Nethermind's edits are mostly un-gluing inline code that the HTML scrape fused to neighbouring words.
